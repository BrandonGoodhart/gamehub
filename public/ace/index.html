Why a proxy? With a key in the browser, the page only ever suits someone running it for themselves. A proxy keeps the key on a server you control, which is the only safe way to let other people use this page. This repo ships a Netlify function at netlify/functions/ace-chat.ts — set ANTHROPIC_API_KEY or GEMINI_API_KEY in your Netlify environment variables, deploy, and point this field at /api/ace-chat.
